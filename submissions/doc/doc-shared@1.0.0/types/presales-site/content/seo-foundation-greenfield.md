**0-1 项目的优势是没有历史包袱：没有旧 URL 要迁、没有冗余页要清理，搜索与 AI 可见度的基础设施可以从第一天按规范建设，降低后续调整成本。**

<!-- table: 第一天做对的 SEO/GEO 地基 -->
| 地基项 | 第一天怎么做 | 不做的代价 |
|---|---|---|
| 语义 URL 与信息架构 | Collection 与产品 URL 按品类语义命名，上线后不再调整 | 后期改 URL 要做跳转、权重被稀释 |
| 结构化数据 | Product、FAQPage、BreadcrumbList、Organization 按页面类型输出 JSON-LD | 搜索结果缺少富结果展示，AI 抽取事实更难 |
| 图文分离与 Metafields | 规格、卖点、FAQ 以文本和 Metafields 承载，不做成长图 | 长图里的文字搜索引擎与 AI 读不到 |
| robots 与 llms.txt | robots 对 GPTBot、PerplexityBot、ClaudeBot 开放；提供 llms.txt | 误封 AI 爬虫会在 AI 答案里缺席 |
| 品牌实体一致 | About、PR、Organization Schema 使用同一套品牌事实 | 品牌信息不一致，AI 容易混淆或编造 |
| 分析与监测 | GA4、GSC、像素与邮件工具上线即配置（见工时明细） | 上线初期没有基线数据，效果无法衡量 |

已有渠道资产的承接：{亚马逊 Listing 与评价、社媒与 KOL 内容如何导入或引用；没有写「无」}。
