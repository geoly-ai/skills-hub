**结论：收录绑定的是 URL（域名 + 路径），不是主题或代码。在域名不变、URL 结构保留的前提下，现有收录通常可以延续，不必从头重新收录；实际影响以上线前 URL 清单比对、跳转抽检和上线后 4–8 周的 GSC 观察来验证。**

<!-- table: 重建方式与收录影响 -->
| 情形 | URL 变化 | 对收录的影响 | 我方保障措施 |
|---|---|---|---|
| 同店换主题（Liquid 重构） | 域名与 URL 全部不变 | 收录与权重通常可延续，影响可控 | 上线前 URL 清单比对，上线后 GSC 覆盖率监控 4–8 周 |
| 更换前端架构（Headless） | 域名与 URL 结构 1:1 保留，个别路径调整做全量 301 | 可控：搜索引擎按 301 转移权重 | 301 映射表双方确认，抽检跳转，提交新 sitemap，监控 404 与覆盖率 |
| 更换域名 | 域名变化 | 等同重新收录，恢复周期不确定（不推荐） | 如确需换域名，单独评估迁移方案 |

如果客户现站从未系统做过 SEO：历史包袱小，这次重建可以从一开始按规范建设 SEO 基础设施，降低后续调整成本；效果按「上线后如何验证」一章的指标与观察期衡量。{按 site-audit.md 的实测结果写一句现状，注明日期}

跨平台迁移项目的 URL 结构通常会变化，必须做全量 301 映射；映射表生成方式、抽检比例与切换窗口写在「数据迁移与切换」章。
