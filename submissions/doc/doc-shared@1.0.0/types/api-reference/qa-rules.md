# 质检规则（API 参考）

对齐 skeleton.md 与用户指令的 7 节结构（文档控制与修订记录由引擎生成，不计入编号章节，2026-09-15 第三波去重）。引擎通用规则（T1–T12、L1/L2、R1、C1）不在此重复列出。

| 编号 | 规则 | 判据 | 定级 | 自动/人工 |
|---|---|---|---|---|
| API-01 | 必备章节齐全 | skeleton.md 中 required=是 的 5 节都能匹配到标题或锚点（文档控制与修订记录由引擎按 doc.json 生成，不计入正文必备章节） | 必改 | 自动（引擎 S1） |
| API-02 | 每个接口有请求 / 响应表与示例代码块 | 「接口详情」节每个直属子标题（接口）下含至少 1 个表格与 1 个标语言的代码块 | 提示（试运行；原定 必改） | 自动（qa_rules.py） |
| API-03 | 错误码表覆盖全局通用错误码 | 「通用约定」节含错误码表，且至少含鉴权失败、限流两类通用错误码 | 提示（试运行；原定 必改） | 自动（qa_rules.py） |
| API-04 | 每个接口标注权限要求 | 「接口详情」每个直属子标题（接口）下：表格「权限」列非空，或正文写「权限：…」（2026-09-15 W3-A 放宽：样张与模板用段落写权限） | 提示（试运行；原定 必改） | 自动（qa_rules.py） |
| API-05 | 幂等性逐接口标注 | 每个写接口：请求表「幂等」列取值 是/否，或正文提及幂等（如「幂等：是」）；GET、HEAD、OPTIONS 按 HTTP 语义豁免 | 提示（试运行；原定 建议） | 自动（qa_rules.py） |
| API-06 | 代码块标注语言 | 围栏代码块后紧跟语言标识，且在 allowed_languages 内 | 提示（试运行；原定 建议） | 自动（未标语言由引擎 L8 建议；语言白名单 qa_rules.py 常量 ALLOWED_LANGS） |
| API-07 | 变更记录每条标注是否破坏性 | 「变更记录」表格含"破坏性"或"breaking"列 | 提示（试运行；原定 必改） | 自动（qa_rules.py） |
| API-08 | 弃用接口有替代方案与下线时间 | 「兼容与弃用」节表格（若存在）含"替代方案""下线时间"两列且非空 | 提示（试运行；原定 必改（该节存在时）） | 自动（qa_rules.py） |
| API-H1 | 输入约束描述准确、类型与取值范围真实可用 | — | — | 人工 |
| API-H2 | 副作用（如触发通知、扣减库存）是否显式写出，不需要调用方试错发现 | — | — | 人工 |
| API-H3 | 错误恢复建议是否可操作 | — | — | 人工 |
| API-H4 | 与关联 tech-spec 「接口设计」节的字段是否一致 | — | — | 人工（跨文档一致性，见 OPEN-QUESTIONS.md） |

## 人工检查清单

- [ ] 鉴权方式具体到可执行（凭证放在 Header 的哪个字段、Token 怎么获取）
- [ ] 每个接口的示例请求 / 响应字段与「接口详情」表格描述一致
- [ ] 限流数字具体（次数 / 时间窗 / 维度），不是"请勿频繁调用"这类空话
- [ ] 变更记录的破坏性变更写清了影响范围与迁移建议

## 伪问题（不要报）

- 「限流与重试」「兼容与弃用」两节缺失（按需章节，无限流策略或无弃用接口的初版可以不写）。
- 某接口"行为/副作用"栏写"无显式副作用"（纯查询接口，如实标注不算漏项）。

## 实现说明（W3-A，2026-09-15）

- 自动规则由同目录 qa_rules.py 实现，新规则一律定级「提示」试运行（doc-qa/SKILL.md「类型包接入」），「原定」为本表原定级；样张与真实文档校准后用 pack.json qa.severity_overrides 升级。校准结果见 ~/workspace/docs/doc-skill-platform-2026-09-15/wave2/qa-calibration.md §6。
- 与引擎重复的判据不在 qa_rules.py 重复实现，「自动/人工」列写明由哪条引擎规则执行（S1 必备章节、S3 编号重复与跳号、L8 代码块语言、R1 绝对化用语、T11 验收列空泛词、X2 图表未引用）。
- 跨文档规则用 ctx.related(type, role=…)：按 role 精确命中且可读才用；读不出、或同类型未写 role 的条目多于 1 条时按关联文档缺失处理（pack.json related 的 for_gate 为真时必改）；同类型未写 role 的条目恰好 1 条时兼容读取并提示补 role（迁移期回退，契约定 role 必填后删除）。
- 数据块（CSV）各行共用指令行号，逐行问题报全文级（行号 0），摘录写数据文件与 CSV 行号，避免被「同规则同行只留一条」合并。
- 关键数字（X4）与高亮限额（H1–H3）口径在 pack.json qa.key_figures、qa.highlight_limits 声明；key_figures 定级一律提示试运行，X4 只查多处取值是否一致，不查数字是否存在或正确。
