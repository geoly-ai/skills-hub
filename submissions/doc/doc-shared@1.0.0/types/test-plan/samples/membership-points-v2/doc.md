# 会员积分系统 v2 测试计划

<!-- summary -->
被测版本：v2.0.0-rc1。测试范围：积分账户、获取、消耗、等级、规则引擎、通知、运营后台七个模块的功能、接口、并发与安全测试。准出标准：P0 用例通过率 100%、P1 用例通过率 ≥ 95%、无未解决 P0 缺陷。

## 1. 测试范围与不测范围

### 1.1 测试范围

## 4. 准入与准出标准

准入标准：冒烟测试（核心链路：注册开户、订单获取积分、积分兑换）通过率 100%，环境部署完成且规则引擎服务健康检查通过。

准出标准：P0 用例通过率 100%，P1 用例通过率 ≥ 95%，无未解决的 P0 缺陷，P1 缺陷数 ≤ 2 且均有明确的上线前修复计划或验证过的临时规避方案。

## 6. 风险与应对

> [!risk]
> 风险：并发压测环境的数据库配置与生产存在差异，可能导致行锁等待表现不一致，压测结论无法直接外推到生产。应对：压测前对齐测试环境与生产的数据库连接池、隔离级别配置，压测报告中显式标注环境差异。

## 7. 缺陷管理

<!-- table: 缺陷级别定义 -->
| 级别 | 判定标准 |
|---|---|
| P0 | 核心链路（注册开户、订单获取积分、积分兑换）不可用，或造成资损（如重复扣积分、超卖） |
| P1 | 主要功能受影响但有临时绕过方式，或影响单一模块但不影响核心链路 |
| P2 | 次要功能或体验问题，不影响核心业务判断 |
| P3 | 轻微问题（文案、样式），不影响使用 |

流转：新建 → 待确认 → 处理中 → 待验证 → 已关闭；P0/P1 缺陷需在 24 小时内确认责任人，验证不通过打回处理中。
