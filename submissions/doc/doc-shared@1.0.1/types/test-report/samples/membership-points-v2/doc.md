## 6. 风险与建议

> [!risk]
> 风险：规则灰度切换的秒级延迟（DEF-003）在大促窗口高频调规时可能被放大感知。监控指标：规则切换实际生效时间与配置时间的差值，工具：rule-engine-service 的可观测性看板（见 tech-spec §9），观察周期：灰度期 7 天，若延迟持续超过 60 秒需提前到下下个迭代修复而非按原计划排期。

> [!risk]
> 风险：三条阻塞用例覆盖的月度周期性行为（保级、风控超时放行）要到下个自然月才能完整验证。监控指标：等级降级异常投诉量、风控放行工单量，工具：客服工单系统，观察周期：下个评定周期（2026-09-01 起）7 天内，出现异常需立即执行 tech-spec §8.2 的回滚判据评估。
