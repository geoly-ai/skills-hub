# 写作约束快照（测试用例）

无上游快照，本包自定（decisions.md ⑨）。检索记录同 test-plan 包：lark-doc genres 中无对应"测试用例"体裁，sop-tutorial.md 的"可重复执行步骤"性质接近测试步骤的写法，但测试用例是数据表而非叙述性操作手册，不适用其体裁规则，不作为快照来源。

## 本包自定的写作约束

- 载体：decisions.md ⑧A——源数据用 CSV 或 YAML，PDF 与飞书文档渲染成表；不做与飞书电子表格的双向同步（阶段 2 候选，见 design.md §5.7）。
- 语气：动作导向、可复现。步骤与预期结果要能被不了解背景的执行者直接照做，不依赖"默认你知道…"的隐含前提。
- 与 test-plan 的边界：测试计划的需求覆盖矩阵读取本包的 data/cases.csv 做统计；测试用例正文不重复贴测试策略或准入准出标准。
- 与 test-report 的边界：测试用例是静态设计产物；测试报告记录某次执行中每条用例的实际结果（通过/失败/阻塞），不修改用例本身的设计字段。
