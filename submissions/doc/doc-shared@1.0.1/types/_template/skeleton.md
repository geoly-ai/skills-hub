# <类型名> 骨架说明

pack.json 的 skeleton 是机器可读版本（S1 必备章节检查用）；本文件写给写作者：每节写什么、写到什么程度、常见错误。两处章节 id 必须一致。

| id | 章节 | 必备 | 必须回答 | 常见错误 |
|---|---|---|---|---|
| doc-control | 文档控制与修订记录 | 是 | 状态、owner、评审人、关联文档 | 修订记录不随版本更新 |
| summary | 摘要 | 是 | 一句话问题、结论或推荐、主要代价 | 写成背景复述 |
| body | 正文示例节 | 否 | 按类型改写 | — |
| open-questions | 未决问题 | 是 | 每条 owner 与截止日期 | 只有问题没有 owner |
| glossary | 附录：术语表 | 否 | — | — |

## D1 骨架确认

outline.md 按上表列章节，每节一行「本节回答什么」；需要用户拍板的点用字母选项列出（全局约定「决策报告的出法」）。用户确认后 run_state.py pass-gate --gate D1 --evidence "<用户原话>"。
