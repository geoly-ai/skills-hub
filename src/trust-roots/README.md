# 内置信任根

🔴 **这是整个验签体系唯一的信任输入。**

`sigstore-public-good.json` 是 Sigstore 公共实例的 TUF 根，**编译进包**（`package.json`
的 `files` 含 `src`），随 CLI 一起分发。

## 为什么必须内置

`docs/m0/02-registry.md` §8.1 要求信任根随 CLI 内置。理由是：验签器本身不认证信任根——
它只负责「按这个根去验」。**一旦这个根来自网络或缓存，对手可以自带 CA + CT log + Rekor，
整套验证会一次性失守，而且全程显示「验签通过」。**

所以：

- **绝不从网络读**，也不从用户可写的缓存读
- **绝不接受命令行/环境变量覆盖**
- `--offline` 下必须照常可用（本来就不出网）

⚠️ §8.2 自己承认过，「内置 + npm provenance」这一跳不是自洽闭环——
根的真伪最终依赖发包渠道。这是**已知的**信任边界，不要假装它不存在。
