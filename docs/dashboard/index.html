skills-hub 埋点面板

聚合全在浏览器里算。除了读同目录的 data.json，这个页面不访问任何外部地址。

事件里有且仅有这些字段： at（秒级时间）、eid/install_id（随机 UUID）、 cli/node/os/arch（版本与平台）、 kind（操作）、result（结果）、artifact/version（制品坐标）、 client（claude/cursor/codex/agents）、scope（global/project）、 ms（耗时）、reason（我们自己的短代码）。
没有路径、目录清单、文件内容、用户名、邮箱、命令行原文、异常栈。 install_id 是本机随机 UUID，与账号无映射，删掉即换身份。
