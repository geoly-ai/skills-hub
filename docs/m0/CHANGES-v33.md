## ① 🔴 `nlink != 1` 会让每一个正常 tx 都无法成像

v32 写「一律拒绝 `nlink != 1`」。评审指出：
**Linux 上正常目录的 link count 本来就 > 1** —— 这条规则会把**每一个正常的 tx** 判死。

v33：🔴 **`nlink` 检查只针对普通文件**，绝不对目录做。

## ② `geoly-tx-v1` 的身份边界

| 评审 | v33 |
|---|---|
| **tx 根目录被排除**在外 → 改根目录的 mode 摘要不变 | 根目录以 `path = ""` 的 `dir-entry` **计入** |
| 已纳入的条目**没规定 xattr / ACL**，与 §01-6.2 的原则不一致 | 🔴 xattr / ACL **不进摘要，因此一律拒绝**：任一条目（含根）带它们 → **无法成像** |
| 「精确匹配 / tx 身份」的表述**过强** | 改为明确**身份等价类** =「路径 × 条目类型 × mode × 文件内容」；等价类之外的一切要么强制规范化、要么拒绝。在该等价类内除 SHA-256 碰撞外无同摘要构造 |

## ③ `quarantine-tx` 的三处收口

| 评审 | v33 |
|---|---|
| 路径写成「当前 repair generation」——**它与 `child.generation` 不同** | 明确用 **`repair-intent.generation`** |
| 「slot 可解释」是**自然语言占位** | 换成**封闭表**：按原 journal 的 `direction` / `op` / `state` 三元组判定哪个 slot 有效、期望摘要取 `old_digest` 还是 `new_digest`；🔴 其余组合一律不允许用这个 source |
| 🔴 三次校验**抓不住目录结构变化** —— 复制途中给源加一个**空目录**，`geoly-tree-v1` 不覆盖目录，stage 与最终 target 仍是同一摘要，**却已违反「制品禁止空目录」** | 加到**五次**：复制前/后各验一次**隔离 tx 的 `geoly-tx-v1` 指纹**（后验能发现持续性篡改）；stage 完成后与最终落位后，除摘要外**重跑完整结构校验**（目录、空目录、类型、mode、身份元数据）。<br>并如实写明：**瞬时改写无法由普通递归复制完全证明**，但 stage 的结构校验足以阻止错误树落位 |
