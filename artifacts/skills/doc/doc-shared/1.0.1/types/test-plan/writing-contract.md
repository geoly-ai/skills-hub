## 本包自定的写作约束

- 语气：计划性、可核验、避免"尽量""争取"这类不可核验的措辞，尤其在准入准出标准与进度节。
- 与测试用例包（test-cases）的边界：测试计划是"怎么测、测到什么程度算过"的策略性文档；测试用例是"具体测什么、怎么测"的数据表。测试计划的需求覆盖矩阵引用测试用例包的 data/cases.csv 做交叉统计，不在测试计划里重复贴用例明细。
- 与测试报告包（test-report）的边界：测试计划定义准入准出标准；测试报告汇报实际执行结果是否达到该标准，二者的判据必须一致，不能测试报告另起一套口径。
