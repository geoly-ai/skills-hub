## 各节写法要点与反例

### 摘要（`<!-- summary -->` 块，不是编号章节）
- 要点：① 机会用一句话说清「什么市场缺口 / 什么用户问题值得投入」。② 目标用户与建议各一句，不展开论证。③ 所需投入给量级（人力、周期、预算区间），不写"需要投入资源"这类空话。④ 摘要要能让读者不看正文就知道要不要往下看——它会被引擎单独渲染成一页。
- 反例：「本文分析了会员积分市场的机会」——没有说清机会是什么、给谁、要投入多少。

### 市场概况
- 要点：① 每个市场数字紧跟来源与年份，同一数字不同来源要标注差异。② 区分市场规模（存量）与增速（趋势），不要混为一谈。③ 趋势判断要有至少两个时间点的数据支撑，不能只凭一个季度下结论。④ 不用「市场很大」这类无法核实的定性描述替代数字。
- 反例：「积分营销市场规模巨大且快速增长」——巨大是多少、快速是百分之几、数据哪年的，都没有。

### 目标用户与细分
- 要点：① 细分要互斥且可触达（能通过现有渠道识别并触达）。② 每个细分配画像（行为特征，不只是人口统计）与痛点证据（数据或访谈引用）。③ 细分数量控制在能落地的范围（通常 2–4 个），不要为了显得全面罗列过多细分。④ 画像不能是内部拍脑袋的刻板印象，需标来源。
- 反例：「细分：年轻人、中年人、老年人」——既不互斥（年龄段模糊重叠）也无画像与痛点证据。

### 竞争分析
- 要点：① 竞品矩阵用维度 × 竞品的表格，每格填 ●（完全具备）◐（部分具备）○（不具备），并在表格下方或脚注给依据来源。② 竞品选择要覆盖直接竞品与替代品，不只挑弱于自己的对手。③ 差异化机会要从矩阵的空白格推导出来，不能凭空写。④ 不只列竞品优点，也要写竞品的真实弱点及依据。
- 反例：矩阵每格都打 ●，或矩阵下没有任何依据说明——质检 MRD-02 只检查「有依据列或脚注」的存在性，但人工复核必须判断依据是否成立、是否只列了优点。

### 用户需求与优先级
- 要点：① 每条需求 MR 编号唯一，标来源（访谈 / 数据 / 竞品对标 / 内部假设，内部假设要明确标注不是用户证据）。② 优先级要基于需求出现频率或影响面，不是内部偏好排序。③ 需求粒度要能转化为后续 PRD 的输入，不要写成功能规格。
- 反例：「MR-003：要做得比竞品好看」——不是可追溯、可转化为需求的表述。

### 定位与价值主张
- 要点：① 一句话定位要具体到"为谁解决什么问题、比替代方案好在哪"。② 与竞品的差异要点名对比对象，不能空泛地说"更好"。③ 定位要与前文的细分、竞争分析逻辑自洽，不能凭空出现新的差异化主张。
- 反例：「我们的定位是最懂用户的积分系统」——最懂体现在哪、比谁懂，无法验证。

### 商业模式与定价假设
- 要点：① 假设要写清是什么、为什么这样假设。② 每条假设配验证方式（怎么测、什么时候有结论）。③ 定价假设要和竞争分析里的竞品定价做对比说明，不能孤立给数字。
- 反例：「假设用户愿意为高级权益付费」——愿意付多少、怎么验证，都没写。

### 进入策略与里程碑
- 要点：① 渠道要具体到可执行的动作，不写"多渠道推广"这类空话。② 节奏要与里程碑挂钩，写清阶段判据。
- 反例：「全渠道推广，快速起量」——没有具体渠道、没有判据。

### 风险与假设
- 要点：① 关键假设要点出"如果这个假设不成立，结论会怎么变"。② 验证计划要写清方法与时间点，不能只说"持续观察"。
- 反例：「假设市场会持续增长」——如果不增长会怎样、什么时候能判断，都没写。

### 数据来源
- 要点：① 逐条列出正文引用的每个数字对应的来源与日期，做成清单方便核验。② 来源要具体到可复核的程度（报告名 + 发布方 + 年份，或内部系统 + 统计口径），不能只写"行业报告"。
- 反例：来源栏写「网络数据」——无法复核，等同于没有来源。
