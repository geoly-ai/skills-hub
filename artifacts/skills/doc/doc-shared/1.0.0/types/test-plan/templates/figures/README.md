# 测试计划图源说明

| 文件 | 类型 | 用途 |
|---|---|---|
| coverage-heatmap.fig.json | svgkit 热图模板（本包自拟 schema） | 第 8 节「需求覆盖矩阵」的可选可视化补充；design.md §5.5 明确该矩阵默认走数据块（<!-- data: data/coverage.csv -->）渲染表格，热图是可选的直观呈现，不是必备 |

需求覆盖矩阵的主呈现方式是数据表（见 templates/doc.md 第 8 节的 <!-- data: --> 块），因为表格能精确显示每个 REQ 的覆盖用例数与状态；热图更适合模块 × 优先级的宏观分布概览，两者可以同时出现（表格给细节，热图给概览），也可以只用表格。
