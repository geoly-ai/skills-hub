## 本包自定的写作约束（不来自 lark-doc）

- 语气：分析性、结论有数据支撑，允许比 PRD 更强的论证语气，但结论仍要能回链到「数据来源」节。
- 与 business-analysis.md 的一个共同点（人工判断参考，非硬性引用）：现状数据与预测分开、估算标注置信范围、不得从公开标价直接推断销量或份额——这一条与 MRD-05（数字有来源年份）精神一致，写作时建议遵循，但不作为自动质检的判据来源。
- 与 PRD 的边界：MRD 回答"要不要做、给谁做、比对手强在哪"；PRD 回答"具体做成什么样、怎么验收"。MRD 的 MR 编号需求是粗粒度的市场需求，PRD 的 REQ 编号需求是可验收的产品需求，两者不是一一对应关系，一条 MR 可能拆成多条 REQ。
