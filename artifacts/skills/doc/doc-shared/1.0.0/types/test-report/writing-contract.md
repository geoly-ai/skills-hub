## 本包自定的写作约束

- 语气：结论先行、可比对。准出结论必须是"建议发布 / 不建议发布 / 有条件发布"三选一，不用模糊措辞（见 skeleton.md）。
- 编号一致性（design.md §5.7 明确要求）：本文档引用的 TC 编号必须能在关联 test-cases 找到；准出标准的比对依据必须与关联 test-plan 的第 4 节「准入与准出标准」逐条对应，不能另起口径。
- 与 test-plan 的边界：test-plan 定义标准（面向未来，测试开始前写），test-report 汇报结果（面向过去，测试结束后写）。同一份准出标准只能有一个权威版本，出现在 test-plan；test-report 只能引用，不能修改口径。
