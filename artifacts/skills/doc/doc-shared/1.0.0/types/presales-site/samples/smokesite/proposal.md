## 2. 关键问题前置

客户最担心的问题：改版会不会影响现有 SEO 排名与收录？

答案：本方案保留域名与 URL 结构，仅对信息架构做非破坏性调整（分类页 URL 不变，仅新增结构化数据与内部链接优化），迁移期设置 301 重定向清单并在上线后 72 小时内逐条核验收录状态，不承诺排名只升不降（承诺排名保证违反 R1 绝对化用语规则）。

<!-- table: 影响对比 -->
| 维度 | 维持现状 | 本方案 |
|---|---|---|
| SEO 收录风险 | 无变更风险，但结构性问题持续 | 保留 URL 结构，增量优化，风险可控 |
| 转化路径 | 现有模板路径冗长 | 模块化改造缩短路径 |

## 5. 技术方案

方案 A（推荐）：Shopify 同店改版，沿用现有 Liquid 主题基座做深度定制。优势：周期短、保留现有 App 生态与订单数据无缝。局限：主题层受 Shopify 平台约束，部分自定义交互需要额外开发。适用阶段：本次上线窗口。

方案 B：Headless（Hydrogen）改造。优势：前端自由度更高。局限：需要额外的前后端分离运维成本，周期更长。适用阶段：若下一阶段流量规模显著增长可评估。
