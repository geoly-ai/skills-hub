主张与「两种纸」

别的 registry 展示「有多少人在用」；我们展示「这东西是谁签的、谁审的、从哪来的、现在还能不能用」。 于是页面上不出现任何使用量数字，布局里也不给它们留位置。

视觉方向借鉴 Claude / Anthropic：暖象牙底、衬线标题、clay 强调、充裕留白。 但我们的信息密度远高于 claude.ai —— 64 位摘要、字段表、成员关系、四格验证。 解法是两种纸：叙述用叙述纸（象牙、衬线、68ch 量度、松行距）， 数据落进记录纸（凹陷的暖灰底、等宽、10px 行距、发丝线）。 留白花在记录纸之间，不花在记录纸里面；衬线字永不进入记录纸。

为什么 yanked 用的是一张灰纸，而不是一张更红的纸

整页都是暖的。把暖色撤掉，在一片象牙里比再加一点红更刺眼，而且它不惊悚—— 它读起来像「这条记录被划掉了」，不像「系统出错了」。真正的强度来自 3px 顶边 + 饱和度归零 + 连链接的 clay 下划线一起撤掉，三个通道叠加，一个都不靠喊。

02

字体与排版尺度

Anthropic 自有的 Anthropic Sans / Serif / Mono 拿不到，但他们自己公布过替代品： Sans → Inter，Serif（Tiempos 一脉）→ Source Serif 4； JetBrains Mono 则直接出现在他们 docs 的样式表里。三个都在 Google Fonts 上。
🔴 等宽字从「主力」降为「引文体」：字段名改用 sans，只有机器原文（标识符、摘要、命令、字面值） 才是等宽。等宽覆盖率从约六成降到约三成，页面因此暖下来，而等宽重新有了意义—— 「这一段是可以逐字节拿走的引文」。复制保真度不变：值仍是 mono + user-select:all。

03

三条状态轴，形状族彻底分开

🔴 这是全设计里最容易做错、做错代价最大的一处。三条轴说的是三件不同的事， 形状族 = 轴，族内形态 = 取值：生命周期是方族（填充度），验证是圆族，本地比对是等号族。 全族里只有圆族有勾，而且那个勾被圆圈住——所以任何一个勾都只可能是「我们这一次验过了」。 再叠一条颜色纪律：全站只有一处绿色，就是验证轴的 verified。 published 是维护者的处置，不给绿色（给了就会被读成「验过了」）； 「两串字节相等」也不给绿色（相等本身不构成担保）。

A · 生命周期 lifecycle

来自快照 record 的 status 字段（已被签名覆盖）。 表达维护者的处置。载体是描边 chip，字面值小写原样。

B · 验证 verification

resolveCurrent() 本次运行的结果，不在快照里。 只在验证链四格里出现，全站别处不得使用，所以它没有 chip 形态。

C · 本地比对 local comparison

「工作树载荷重新打包出的摘要和 record 里那个相不相同」——就是拿两串字节比了一下。 既不是处置，也不是担保，所以无外框、无绿色。

旧方案的两个缺口，这一版是这样堵上的

旧实现里生命周期的 published 与验证的 verified 共用 i-check，deprecated 与 stale 共用 i-bang——于是「维护者说可以装」和「我们验过了」在界面上成了同一件事。 新方案里 i-bang 整个删除（deprecated 改用半填充方，stale 改用圈内钟）， 勾只存在于圆族。实现方可以直接用一条静态检查兜底： l-* 只允许出现在 .life 与 .notice.n-yanked / .n-degraded / .n-deprecated 内； v-* 只允许出现在 .chain 与 .notice.n-failed 内； c-* 只允许出现在 .cmp 内。 （本演示页 §03 的图例区 .axisrow 豁免——那里要把三族并排给人看。） 🔴 .notice.n-failed 必须是独立的类，不许复用 .n-yanked：复用等于把「验签失败」和「被撤回」在 CSS 身份上合并回去， 图标分开了、纸样又把两条轴粘回来了。

状态警示条

这些是事实，不是错误：没有大图标、没有满色实心条、没有感叹号轰炸。 统一形态是「一根顶边 + 一张纸 + 一句陈述句标题 + 可执行的下一步」。 三者纸样不同、顶边粗细不同、图标不同、措辞的主语不同： yank 是「它被撤了」，degraded 是「它被别人拖累了」，deprecated 是「不推荐了，但仍可安装」。 🔴 语义结构用 role="group" aria-labelledby， 不用 role="alert" / role="status"—— 那两个是 live region，会把页面既有的静态事实朗读成「刚刚发生的事」。

动效与可访问性

hover / press
背景与边框 120ms linear。只改颜色，不改尺寸——列表行不许在 hover 时位移。
复制反馈
「复制」→「已复制」，颜色切到 --c-clay-ink，1200ms 后复位。无缩放、无弹跳。 🔴 不许用绿：绿在本站点只表示「验证轴验过了」，一个复制成功不是验证结论。
折叠展开
grid-template-rows: 0fr → 1fr，160ms ease-out。
加载中
静态占位横线，不做 shimmer 扫光：那会让「还没验证完」看起来像已经有内容了。
焦点
outline: 2px solid var(--c-clay); outline-offset: 2px，无过渡。
禁止
入场动画、滚动触发动画、视差、数字滚动、渐变流动、页面切换过渡、任何 >200ms 的过渡。
对比度
正文级用途 ≥ 4.5:1，大字/图标级 ≥ 3:1。🔴 --c-clay 在象牙底上只有约 3:1，不能当正文色；文字用 --c-clay-ink。
live region
只给真正动态的两件事：验证完成、已复制。警示条用 role="group"，不用 role="alert"。
颜色不是唯一通道
三条轴各有独立形状族；Tier 另有计量条；状态永远同时给词。
